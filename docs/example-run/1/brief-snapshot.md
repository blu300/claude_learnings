# Brief: Book Lending Tracker

I lend books to friends and never get them back, because I forget who has what.

I want something that tracks which of my books are currently lent out, to whom,
and since when — and nudges me when a book has been out for a long time.

It should be quick to record a loan (I'm usually handing over the book at the
time) and quick to see what's outstanding.

I am one person tracking my own shelf. This is not a library system.
